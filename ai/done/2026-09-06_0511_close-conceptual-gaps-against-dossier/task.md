# Close Conceptual Gaps Against Dossier v2.1

Close four gaps between the AILedger 2.0 v0.1 kernel and design dossier v2.1, so the kernel supports the operator's actual working method — extended brainstorming before any agent is dispatched — and moves toward a learning, self-correcting kernel for large cross-repo work.

1. Add a typed escalation object so only a business decision or a true unknown can reach the operator.
2. Model rejected alternatives so a discarded approach survives and cannot be silently re-proposed.
3. Add the `work.complete` and `work.block` lifecycle commands, and stop treating a provider process exit as work completion.
4. Make `Constraint` a first-class state object instead of one hardcoded sentence.

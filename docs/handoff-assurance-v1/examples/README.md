# Inspect the installed task-13 example

This is a scripted, disposable fixture from the exact installed implementation. It is not Uri's
client trial or evidence of better model judgment, delivery time or cost. Paths, identities and
receipts are historical observations, not reusable authority. No model process ran.

1. [Partial report](partial.json) and [recovered report](recovered-partial.json) have the same
   receipt ID, content hash and candidate binding. The later response is a replay, not a new verdict.
2. [Independent evidence](independent-evidence.json) retains the exact successful tool exchanges
   referenced by acceptance: reviewer/verifier reports, their own read receipts and the actual host
   check. Inspect distinct principals/sessions, exact captured candidate/requirement/source content,
   criterion observations and the actual process/environment output. These are scripted assertions;
   a real trial must judge the substance.
3. [Explicit acceptance](accepted.json) binds that original candidate and independent reports to an
   authorized decision. [Changed candidate](changed.json) preserves original history with exact
   `candidate changed: a.txt` reassessment reasons. [Dependency comparison](affected-unaffected.json)
   shows dependent `b` needing reassessment while unrelated `c` remains current.
4. [Repair remains unaccepted](repaired-unaccepted.json). The shell check uses command substitution,
   which discards trailing newlines, so it misses the deliberately extra newline. A successful check
   is not semantic proof. The probe explicitly leaves this repair unaccepted.
5. [Interrupted host check](interrupted.json), [operator reconciliation](reconciled.json) and
   [post-reconciliation view](after-reconciliation.json) show unknown remaining unknown. The
   probe hard-killed only its own disposable process group. Reconciliation did not create a successful
   ending or silently rerun the old key; the [exact partial checkpoint retry](interruption-checkpoint-retry.json)
   preserves the original receipt unchanged.

[Probe report](report.json) states installed identity and remaining limitations. The installation
receipt contains hashes for these JSON files and the complete original transcript's local path/hash.
`independent-evidence.json` is an explicitly selected subset of exact transcript rows; it is not a
substitute for the full transcript when counting interactions. Reproduce with the command in
[checkpoint F](../trial.md), using a fresh output directory. It creates no governed development history.

# Falcon Adaptive Pressure Strategy

Design and implement a pressure-aware Falcon Spotlight findings collection strategy that can scale page size up and down while preserving cursor correctness, reducing Falcon backend pressure, and improving large-tenant collection time.

The work must use local Falcon documentation under `src/Cymulate.Integration.Adapters/Collectors/FalconCollector/FalconDocs/`, current collector behavior, and prior cursor recovery decisions. It must produce an `analysis.md` file before implementation so the programmer and verifier work from a durable reference.

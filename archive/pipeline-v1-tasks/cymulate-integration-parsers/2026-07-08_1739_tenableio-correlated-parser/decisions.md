# Decisions

- **D1**: One parser_key serves both collector generations; routing rides `input_mode` (split → deprecated delegate, hydrated → new declarative correlated lane). Rationale: parser deploys before the collector; old split data keeps flowing in the interim.
- **D2**: NO `stamp_asset_id`/`stamped_uuid` for Tenable.io — use `dedup_key` on `host.id` + `link_to_asset` join (finding `asset.uuid` ↔ asset `aid`). Rationale: hosts span multiple chunk envelopes; random stamping duplicates assets downstream (exposure-analytics demote-churn defect).
- **D3**: Reference idiom is `tenable-sc-assets-findings.yaml` + per-parser fns module; mirror its structure/style except D2.
- **D4**: Split-mode code path stays byte-equivalent — delegate class untouched; router only dispatches.
- **D5**: Fixtures are cut from the real 17 GB sample run (multi-chunk, zero-findings, normal hosts), not hand-invented.
- **D6**: Commit at end of pipeline; push only on explicit user go-ahead.
- **D7 (execution pivot, supersedes the "new declarative yaml lane" wording in the contract Goal)**: the correlated lane is implemented INSIDE the hand-written delegate — the hydrated branch shape-sniffs the envelope grammar and a new `TenableAssetsAndFindingsCorrelated` handler derives the two split lanes (`host.*` → existing `_build_asset_envelope_df`; `explode(findings)`), then the split path's uuid-correlation machinery runs verbatim. Justification: (a) the declarative engine cannot reproduce the dynamic per-sub-field plugin flatten that defines today's finding `additional_fields` contract — a frozen explicit map of ~50 drifting plugin keys is a parity downgrade; (b) exact parity by construction, ~60 lines vs a ~200-line spec+fns+router; (c) repo precedent for THIS parser lineage (NotHydrated split handler, CrowdStrike correlated) extends the delegate, while SC went declarative as a fixed-schema rebuild. The yaml spec stays the registry delegate shell (comments updated to document the three generations).
- **D8**: split-mode `is_split` gates generalized to `correlates_by_uuid` (split OR correlated); legacy hydrated path bit-identical (gates false), split path bit-identical (gates true, same code).

- [SEVERITY: minor] `cortexXdrAssetsAndFindings.py:46` — asset `type` mandatory field path is `"type"` with default `"Host"`. The hydrated sample emits `"type": "endpoint"`. `BaseParser.post_process` lowercases (no enum normalization on `type`); resulting value will be `"endpoint"`. The DB enum for asset `type` typically accepts `host`; downstream may reject `"endpoint"`. Out of strict contract scope (not in Success Criteria nor a base-parser raise), and matches the pass-through-normalizer assumption (collector owns mapping). Operator/collector decision — flagged for awareness only.
- [SEVERITY: minor] `cortexXdrAssetsAndFindings.py:202` — `findings_source_df` from the empty-vulns branch only carries `_row_asset_id`. `extract_module_data` correctly falls through to defaults for absent paths, but the resulting `findings_df` will contain zero rows with an `_anchor_expr_to_dataframe`-anchored schema. Confirmed safe via `BaseParser.extract_module_data` semantics; no action required.
- [SEVERITY: minor] `cortexXdrAssetsAndFindings.py` — does not declare `group_names` / `site_names` in `asset_mandatory_fields`.
